> 更新日期：2026-10-23  
> 适用对象：E-01 及后续展馆的程序化建筑。  
> 实现位置：`src/worlds/cyberpunk/buildings/buildings.ts` 的 `gallery()`；世界坐标与交互配置在 `src/worlds/cyberpunk/layout.ts`。  
> 风格诊断、跨建筑推广建议与参考站原则见 `docs/STYLE_REFERENCES.md`。

> 2026-10-23 V4.0 审阅：全城黑剪影与 CRT 属于候选夜景预设，不默认套用到 E-01；E-01 仍是媒体街区的暗面留白与入口可读性锚点，具体边界见 `AGENTS.md` §1.9 / §1.10。

## 1. 设计意图

E-01 是“暮光街区里的低矮展馆”，不是地标塔楼。它靠三层关系建立辨识度：

1. **远看轮廓**：低基座 + 横向主体 + 偏心灯笼体 + 深色压顶，形成不对称的阶梯剪影。
2. **中看入口**：门头铜牌、雨棚、真实门洞、主橱窗和竖向海报窗，按“招牌 → 入口 → 主展品 → 次级信息”排优先级。
3. **近看构造**：墙体分缝、窗框厚度、门洞侧壁、灯槽、拉杆、落水管和屋面设备都有实体，而不是贴图。

后续建筑应继承“**一个主视觉，两个次级信息，其余退后**”的原则，避免立面被发光方块和平铺灯箱填满。

## 2. 体量与比例

| 构件 | 尺寸（局部坐标，米） | 说明 |
| --- | --- | --- |
| 基座 | 9.4 × 0.30 × 12.4 | 相对 9×12 占地每边外扩 0.2，倒角 0.05，压低以保持门前通行尺度 |
| 主体 | 8.5 × 4.05 × 11.2 | 起于 y=0.30，倒角 0.12 / 2 段 |
| 灯笼体 | 4.4 × 1.5 × 8.2 | 偏心 +1.6，出挑于主体，倒角 0.08 / 2 段 |
| 灯笼压顶 | 4.7 × 0.14 × 8.5 | 每边出挑 0.15，倒角 0.04 / 1 段 |
| 雨棚 | 4.6 × 0.14 × 1.2 | 中心高度 3.42，前伸至 z=7.15 |
| 门头牌 | 3.96 × 0.74 × 0.08 | 中心高度 3.82，位于雨棚上方 |
| 门洞 | 宽 2.36，高 0.30–3.22 | 墙厚 0.46，门面后退约 0.5 |

规则：

- **主体高度不超过宽度的 0.6 倍**，保持横向展馆性格；需要更高时优先增加基座或屋顶体块，而不是直接拉高主体。
- 灯笼体必须偏心，偏移量约为主体的 15%–20%，避免变成对称的“盒子叠盒子”。
- 压顶、雨棚、窗台的出挑控制在 0.10–0.18m；小于 0.08m 在正常游玩距离不可读，大于 0.25m 会显得笨重。

## 3. 材质角色

以下材质角色作为 **A 版暖砂岩样板** 保留；当前高亮霓虹方向可做 **B 版**：主体改深玄武岩 / 炭黑，铜、玻璃、发光角色继续沿用，靠霓虹、屏幕和湿地面反射建立对比。两版都保留本文的门窗、倒角、招牌与验收构造。

| 角色 | 颜色 / 参数 | 用法 |
| --- | --- | --- |
| 暖砂岩 `shell.warm` | `#8c7a6b`，粗糙度约 0.85，细噪点凹凸 | A 版主体、墙垛，面积最大，负责整体暖色；B 版改为局部强调 |
| 浅砂岩 `shell.light` | `#9d8977` | 灯笼体，抬高上半部明度 |
| 深炭灰 `shell.dark` | `#4a4548` | 压顶、雨棚、女儿墙、分缝、设备外壳 |
| 铜 `Gallery_Bronze` | `#6b523b`，金属度 0.58，粗糙度 0.40 | 窗框、门框、画框、拉杆；只用于线构件 |
| 深铜 `Gallery_DarkBronze` | `#2a241f`，金属度 0.50 | 门头底板、背标底板，避免纯黑 |
| 凹槽 `Gallery_Recess` | `#06070b`，粗糙度 0.96 | 窗洞、门洞背板，负责“深进去”的暗部 |
| 玻璃 `Gallery_Glass` | `#6f8a9e`，透明度 0.06，粗糙度 0.08 | 覆盖在展品前，不遮挡画面；远看只留一层冷反光 |
| 发光金 `emissiveGoldSoft` | 暖金，低强度 | 灯槽、画框灯、雨棚底光；只用细线，不做大面积面光 |
| 发光青 `emissiveCyanSoft` | 青色，低强度 | 只用于导视、编号、航空障碍灯；每栋不超过 2–3 处 |

约束：

- 一面墙最多出现 **两种石色 + 一种金属色 + 一种暗部色**。新增颜色前先确认它承担的是结构、信息还是装饰角色。
- 玻璃透明度保持在 0.05–0.10。超过 0.15 会把后方的展品洗成灰雾，也会产生排序问题。
- 发光材质以“线、小面和屏幕”为主；整面墙均匀发光仍不推荐。大面积屏幕可以高亮，但要有内容层级和暗部，不能让 Bloom 开关失去意义。
- 展品贴图使用 `MeshBasicMaterial`（`toneMapped: false`），保证画面颜色不被场景曝光二次压暗；亮度在 Canvas 纹理阶段校准，而不是靠提高灯光硬拉。

## 4. 倒角与法线

| 部位 | 倒角 | 分段 |
| --- | --- | --- |
| 主体、灯笼体 | 0.12 / 0.08 | 2 |
| 墙垛、翼墙 | 0.035 / 0.03 | 1 |
| 压顶、雨棚 | 0.04 / 0.035 | 1 |
| 门头牌、铜牌 | 0.02 | 1 |
| 细节盒体（窗框、灯槽、拉杆） | 0（用 `BoxGeometry`） | — |

- 只有**会被近景看到的主体积**使用 2 段倒角；细节构件用 1 段或直角盒体，控制三角面。
- 倒角后不要手动改法线；`RoundedBoxGeometry` 的法线已正确。直角盒体保持默认法线，靠材质粗糙度和分缝表达体量。
- 分缝用 0.02–0.045m 厚的深色薄盒，贴在墙面外 0.012m；不要用贴图线，否则斜视会糊。

## 5. 门窗构造配方

### 5.1 入口

按由外到内的顺序叠 6 层，缺一层就会“贴片感”：

1. **墙垛**：把东立面拆成左右墙垛、窗下墙和门头梁，中央留出真实洞口。
2. **背板**：`recess` 置于 z=5.62，形成 0.5m 深暗部。
3. **门扇**：两扇 1.04 × 2.66 玻璃，中心 z=5.74；中缝、边梃、上下冒头均为铜色实体。
4. **把手与侧壁灯槽**：把手 0.62m 高，灯槽 0.024m 宽，贴在门洞侧壁。
5. **门套**：0.14m 宽、0.18m 深的铜色门套，顶部门套高 0.14m，明确洞口厚度。
6. **外部雨棚与门头牌**：雨棚底面加两道纵向灯槽和一排点状灯，拉杆以约 58° 连接到墙面。

### 5.2 橱窗

- 凹槽比画框每边大 0.04–0.06m；铜框厚 0.05m；展品平面再内缩 0.03m。
- 玻璃单独一层，距展品 0.28m；玻璃上方设暗铜遮光盒和一条暖金灯带。
- 窗台用深色石质薄板，前缘出挑 0.05m，给底部一条真实阴影线。
- 主橱窗与入口的距离保持 ≥ 1.2m，避免排队/交互提示遮住门。

### 5.3 侧窗与高窗

- 侧窗必须有凹槽、窗台、左右边框和上亮子；玻璃与墙面错开 0.05m。
- 高窗（灯笼体东立面）用“暗底 + 暖窗面 + 铜压条”三层，尺寸 0.9 × 0.62，间距 1.0m，形成节奏而不是连续发光带。

## 6. 招牌与信息层级

> 大型媒体立面不进入 E-01。整面媒体墙、竖向巨幅和屋顶广告牌属于 T-01 / T-02 / T-03，裙楼色带属于 E-03；E-01 保持门头、橱窗、0.66 × 1.32m 竖向海报和街面小灯箱，作为媒体街区的暗面留白与近景阅读点。规则见 `AGENTS.md` §1.1a。

| 层级 | 内容 | 尺寸 | 亮度 |
| --- | --- | --- | --- |
| 一级 | `GALLERY / 视觉与摄影` | 3.8 × 0.66 | 暖白 `#e4cfb2`，字距 13px |
| 二级 | 主视觉标题 `暮光构造` | 1.2 × 0.2 | 低亮暖灰，贴在窗台下方 |
| 三级 | 竖向海报 `01 / 暮光构造` | 0.66 × 1.32 | 暖金数字 + 冷青小字 |
| 辅助 | 背面 `GALLERY / E-01` | 1.62 × 0.4 | 暖白 + 青色副标 |

排版规则：

- 主标题只用一种字重（500/600），副标用 400；中文与英文之间留 2px 字距，英文主标字距 10–14px。
- 招牌底板用深铜而不是纯黑，边缘保留 0.02m 倒角，避免在夜景中变成一块死黑矩形。
- 编号（E-01、01）使用青色或暖金，面积不超过招牌的 5%。
-  canvas 纹理宽度不低于 1024（门头）或 512（海报），`anisotropy` 设为 8，保证斜视可读。

## 7. 灯光用法

| 灯 | 参数 | 职责 |
| --- | --- | --- |
| `galleryWarm` | `0xffc483`，强度 22，距离 12，衰减 2，位置 `(-10.1, 4.8, 4)` | 立面主光，照亮砂岩与门头 |
| `galleryDoor` | `0xffc07a`，强度 5，距离 4.5，位置 `(-12.25, 2.55, 4)` | 门洞补光，抬起门槛与侧壁 |
| `galleryService` | `0xffb877`，强度 3.5，距离 4.2，位置 `(-25.05, 2.6, 6.1)` | 背面服务门，保证绕行可读 |

- 主光放在建筑**斜前方**，不要正对门洞，否则门套与雨棚会失去阴影层次。
- 补光强度约为主光的 20%–25%，只负责“从黑到可读”，不负责造型。
- 发光灯槽负责视觉引导，实际照明由点光完成；两者不要互相替代。
- 所有效果必须在 **Bloom 关闭、动态反射关闭** 时仍然成立。增强开关只做加成，不承担基础可读性。
- 接地阴影使用贴地径向渐变（`addContactShadow`），尺寸略大于基座，透明度 0.44；不要依赖实时阴影单独压地。

## 8. 可复用构件

后续建筑可直接复制的模式（都在 `gallery()` 内）：

- `wallBlock(x0, x1, y0, y1)`：把立面拆成墙垛，留真实洞口。
- 入口六层配方：背板 → 门扇 → 门套 → 侧壁灯槽 → 雨棚 → 门头牌。
- 橱窗配方：凹槽 → 铜框 → 展品平面 → 玻璃 → 遮光盒 → 灯带 → 窗台 → 说明牌。
- 侧窗配方：凹槽 → 暖窗面 → 玻璃 → 四边铜框 → 窗台灯。
- 背面服务套件：服务门 + 把手 + 门头灯槽 + 背标 + 百叶 + 检修口 + 落水管。
- 屋面套件：女儿墙 + 分缝 + 空调机组 + 排气管 + 天线 + 青色障碍灯。

复制时保留**构造顺序**，但必须重新核对世界坐标、朝向、碰撞体和交互点；E-01 的门户交互点在世界 `(-12, 0, 4)`，返回点 `(-10.5, 0, 4)`，触发半径 1.8m。

## 9. 性能注意事项

- E-01 单独增加约 25 个 draw calls；主要成本来自独立贴图平面、玻璃和未合并的细节。
- 合并规则见 `procedural/merge.ts`：同材质静态网格会合并，但独立贴图、透明体和遮挡壳保持独立。
- 后续建筑优先复用材质实例，不要为每栋楼 clone 一套铜/玻璃；确需改色时只 clone 必要的 1–2 个。
- 阴影投射体控制在主要体块、雨棚、门套和屋面设备；窗框、灯槽、分缝关闭 `castShadow`。
- 宽景视角（05/06）的 draw calls 会因阴影 pass 和外围建筑上升；目标是在 1440×900 下保持 ≤150，超过时优先合并小构件，而不是删细节。

## 10. 验收清单

- [ ] 正常游玩距离能一眼找到入口，门洞有可见深度。
- [ ] 主视觉、海报、门头牌三者互不遮挡，信息层级清楚。
- [ ] 窗框有厚度，玻璃后能看到展品，而不是发光方块。
- [ ] 绕到侧面和背面仍有窗、门、分缝或设备，不出现整面空墙。
- [ ] 关闭 Bloom 和反射后，材质差异与门洞暗部仍然成立。
- [ ] 入口交互提示出现，进入内容页后可返回原位置。
- [ ] 三角面与 draw calls 记录在 README 的性能表中。
