## 候选外观与运动

| 项目 | 当前参数 |
| --- | --- |
| 尺寸入口 | `src/worlds/cyberpunk/layout.ts` 的 `landmark.width / height / position` |
| 候选 | 宽 9m、高 6.9m，外轨半径 4m、内轨 2.92m |
| 基座 | 约 4.41m 直径、0.34m 高的低台；内凹灯圈与四脚分叉支架，移除旧高实心立柱 |
| 两颗球 | 外球半径 0.5m、内球 0.41m；青色/琥珀色金属球，带赤道环和经线 |
| 两轨倾斜 | 候选约 +28° / -39°，另有不同的方位初相位 |
| 沿轨运行 | +0.44 / -0.61rad/s，约 14.3s / 10.3s 一圈 |
| 轨道进动 | +0.024 / -0.018rad/s，约 262s / 349s 一圈 |
| 减少动态效果 | 两轨、两球停在固定相位，沿用既有设置语义 |

宽度是主要运动包络的标称值，小球经纬线装饰可额外增加数厘米。参数范围不是只做整体缩放：宽且矮时会适当减小倾斜角，确保轨道低点不压进步行空间。两颗球使用绝对时间求位置，更新不累加渲染帧位移，原有单一渲染循环每帧调用一次 `update()`。

## 碰撞与通路

外观和物理共用 `props/orreryConfig.ts` 的尺寸计算。`colliders.ts` 注册三个静态圆柱：

- `LM-01:base`：低基座，半径约 2.205m、高 0.34m。
- `LM-01:supports`：支架/轴承的保守包络，半径约 1.85m。
- `LM-01:orbital-envelope`：轨道与双球全部运动的保守包络，半径约 4.58m，下缘约 Y=2.014m，上缘约 Y=6.93m。

最外侧下方可步行，避免用落地实心圆柱封住整个 9m 占地；支架区域仍阻挡角色。跳跃与相机遇到上方包络会被挡住，不会穿入运动轨道。该包络是静态简化，会挡住轨道间部分真实为空的空间；不是逐球/逐轨精确动态刚体。近处镜头收缩的主观效果仍需连续操作检查。

几何脚本检查了 8/9/10m 宽与 6/6.9/8m 高的九组参数，每组采样 240s 的运动范围、两球轨道距离、两球不相交、减少动态效果及绝对时间一致性。真实实例顶点参与包围测量，避免把旋转的环状实例批次包围盒误算成更大的方框。

当前广场碰撞图使用 0.25m 网格和角色半径 0.28m，从出生点可达雕塑东、西、北及两侧绕行点，包含既有楼体、画框、大屏脚座等碰撞。Rapier 形状扫掠另检查了基座阻挡、外轨下方通行、跳跃触及上方包络、相机体积阻挡。上述检查不等于实际绕行或镜头体验验收。

## 三视角与录屏

开发预览启动后可直接访问，完成引导后生效：

- 出生点：`/world?lm01=spawn`，实际出生位置及跟随机位。
- 广场侧面：`/world?lm01=side`，固定侧面审阅相机。
