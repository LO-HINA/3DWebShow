# LM-01：光轨出生庭与页面入口

本记录是 2026-10-24 的最新实现。它替代上一轮 9m × 6.9m、中央实心基座、轨道进动方案；不是对旧方案的尺寸定稿。

## 当前效果与位置

- LM-01 仍在 `[0,0,0]`，候选放大到宽 **14m**、高 **11.8m**。不移动大屏或建筑，按用户要求暂不处理遮挡布局。
- 两个环面固定在不同倾角；每环由五段圆弧组成，细白光芯外分别叠加电光青与蓝紫柔光。环面不再进动或摆动，轮廓保持稳定。
- 每环两枚流光亮点，各带九枚渐弱尾点；两环流光角速度 +0.33 / -0.47rad/s。双球沿轨道运行速度 +0.28 / -0.39rad/s，和流光分别计算，减少动态效果时冻结。
- 球体暂为独立的蓝色大球、浅灰小球，供未来地球/月亮模型替换；当前不声称已完成地月精模或真实天体比例。
- 中央改为平地出生庭，移除原中央圆柱/基座碰撞。四个脚座与拱形支撑移至外围，上方运动包络下缘约 Y=4.272m，普通行走与跳跃留有净空。

出生脚点改为 `[0,0,1]`，人物默认朝向前方控制台。`LAYOUT_VERSION` 已更新，旧布局的会话快照失效，首次载入本版回到新出生庭；此后从页面返回仍恢复已保存的控制台安全点。

## 交互和页面接入

人物出生后可按 **E**，或点击现有 HUD/手机交互按钮，进入 `/world/observatory` 的轨道中枢。控制台站立/返回点为 `[0,0,-0.5]`，物理台体位于 `[0,0,-1.8]`。沿用既有 `PortalSpec → WorldHost → React Router` 流程，不增加另一套输入控制器。

导航页目前有一个真实可用的摄影馆入口和两个待接入项目位。未配置的项目不生成空链接；已有站内路由在同一应用切换，独立页面由明确点击在新标签打开。用户尚未提供其他页面地址，本轮没有猜测或自动连接外站。

接入自己的页面只需修改 [`src/content/observatoryDestinations.ts`](../../src/content/observatoryDestinations.ts) 中的项目对象：

```ts
// 独立网页：同站的另一应用，或完整 HTTP(S) 网址。
target: { kind: 'url', href: '/apps/my-project/' }
// target: { kind: 'url', href: 'https://your-domain.example/' }

// 已注册的 React Router 站内页。
target: { kind: 'route', path: '/world/gallery' }

// 暂不开放。
target: null
```

同一对象的 `title / category / description` 控制卡片文案。增加 React Router 页时还须在 `app/App.tsx` 注册路由并扩展公共 `RoutePath`；已有独立项目不需要迁移到宿主或改角色控制器。

## 文件与模型替换接口

| 文件 | 职责 |
| --- | --- |
| `worlds/cyberpunk/layout.ts` | 天体仪尺寸/位置、新出生点、布局版本 |
| `props/orrery.ts` | 保留公开入口，兼容现有 `createLandmark()` 调用 |
| `props/orreryVisuals.ts` | 分段光轨、流光短拖尾、外围拱架、3D 控制台与双球运动 |
| `props/orreryConfig.ts` | 共用尺寸、支撑曲线、10 个静态碰撞体、控制台交互定义 |
| `exhibits.ts` / `presentation.ts` | 注册 `LM-01-CONSOLE` 与目录位置文案 |
| `content/observatoryDestinations.ts` | 页面入口数据；新增目的地首先改这里 |
| `pages/ObservatoryPage.tsx` / `observatory.css` | 导航页与适配布局，不运行第二个 3D 渲染器 |

模型位为 `LM-01_EarthMount` 与 `LM-01_MoonMount`，根节点随轨道移动和自转。其 `userData.targetRadius` 分别约 0.778m / 0.342m；占位外观独立在 `EarthPlaceholder / MoonPlaceholder` 子组。接入模型时替换该占位子组，保持移动根节点与更新逻辑，记录模型轴向、尺寸和许可；不要让模型动画再次平移球体。

支撑曲线由外观与碰撞共同使用。碰撞为四个脚座圆柱、四个低段支撑包围盒、一个控制台盒和一个高空圆柱包络。高空包络会挡住部分实际为空的轨道间隙，是明确保留的简化；中央地面没有整块实心碰撞。

## 运行与采集

普通探索：`http://127.0.0.1:5173/world`；仪表盘直达：`/world/observatory`。开发审阅入口保留 `?lm01=spawn`、`?lm01=side`、`?lm01=close`，侧面机位随新尺寸调整，近景检查控制台；它们不等于已经取得运行截图。

```powershell
npm run dev
# 在另一个终端中，按需运行：
npm run build
node scripts/check-dependencies.mjs
& '.\node_modules\@esbuild\win32-x64\esbuild.exe' scripts/check-orrery.ts --bundle --platform=node --format=esm --packages=external --outfile=.camera-preview/check-orrery.mjs
node .camera-preview/check-orrery.mjs
& '.\node_modules\@esbuild\win32-x64\esbuild.exe' scripts/check-observatory-page.tsx --bundle --platform=node --format=esm --packages=external --loader:.css=empty --outfile=.camera-preview/check-observatory-page.mjs
node .camera-preview/check-observatory-page.mjs
python scripts/capture-orrery.py
```

采集脚本包括三视角、连续运动，以及 `E → 仪表盘 → 摄影馆 → 安全返回 → 仪表盘 → 出生庭` 的真实操作检查；这些是待执行成功的采集项，当前没有据此验收。后续优先完成实际拖拽、流光亮度/尾长与页面往返，再确定尺寸和正式地月模型。
