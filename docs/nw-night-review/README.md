## 巨幕构成

- **尺寸与朝向**：宽 17m、高 20m、下沿 5.4m，屏幕沿 `curveFront` 凹弧面逐段贴合（20 段），单几何单材质；屏幕法线指向中心 `[0,0,0]`。
- **程序化内容**：1536×1808 Canvas 2D，约 220ms 重绘一次。包含深蓝夜空渐变、星点闪烁、透视网格地平线、霓虹描边楼群剪影、中心脉冲球与三圈椭圆轨道/四颗卫星、`LOHINA` 与 `N I G H T   A T E L I E R · N W ( 0 )`、`虚拟艺廊` 与 `VIRTUAL GALLERY / SIGNAL FEED 07`、竖排侧标、底部滚动信息条、扫描亮带、扫描线与暗角。无外部视频/图片依赖，离线可用。
- **实体构造**：暗色背板（凹进 0.5m）、上下弧形金属轨（半径 0.16）、双侧立柱、5 根竖梃（跨过屏面）、底部检修马道与两侧支架；全部 `userData.noMerge`，不参与静态合批。
- **光与反射**：材质 `MeshBasicMaterial` + `toneMapped:false`，`userData.bloom=true` 进入选择性辉光；共享湿镜面地坪可读到屏幕倒影。屏幕本身是发光面，不是点光源，不额外增加实时灯。

## 已保留的夜景装饰

- 五道弧形檐口灯槽：有厚度的暗槽、下缘细光芯，青色为主，11.42m 层使用暖金，楼冠单独收边。
- 两端嵌入式竖灯、侧墙灯槽/腰线与背面横向光带，绕行时继续能读到建筑结构。
- 玻璃独立调整粗糙度、透明度与环境反射；窗后空间继续使用实体墙、地板、灯与桌体。玻璃目前反射场景环境贴图，不声称已实现逐面实时城市反射。
- 高处短字牌 `LOHINA / NIGHT ATELIER` 与入口标识 `NW(0) / VISUAL ARTS` 形成不同阅读尺度；3 盏不投实时阴影的局部灯继续照亮入口、曲面和侧转角。
- NW 前庭局部湿铺装收为 18×7m，位于本地入口前，避免建筑转 45° 后越过中路；仍复用 CityLook 单一共享反射目标。
