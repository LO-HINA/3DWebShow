## 已接入

- 五道弧形檐口灯槽：有厚度的暗槽、下缘细光芯，青色为主，11.42m层使用暖金，楼冠单独收边。
- 两端嵌入式竖灯、侧墙灯槽/腰线与背面横向光带，绕行时继续能读到建筑结构。
- 玻璃独立调整粗糙度、透明度与环境反射；窗后空间继续使用实体墙、地板、灯与桌体，窗后亮区按连续楼层/开间组织，未以窗户贴图代替构造。玻璃目前反射场景环境贴图，不声称已实现逐面实时城市反射。
- 主图片5.6×5.04m、辅助图片3.2×3.2m，使用现有用户JPG；独立金属壳、凹口和细灯槽。使用原图sRGB、不裁切、不额外染色，图片材质退出辉光选择；整场景输出色彩转换仍保留。
- 高处短字牌与入口标识形成不同阅读尺度；仅新增3盏不投实时阴影的局部灯，照亮入口、曲面和侧转角，没有改变全街区环境光/曝光。
- NW前庭局部湿铺装登记到现有CityLook，复用一个共享反射目标。局部材质支持较柔和采样和轻微扰动，不做整屏模糊。公共地面效果在共享工作区另有并行修改，不能将其整体变化全部归为本样板；本轮没有改 `theme.ts` 的全局地面参数。

## 检查与截图缺口

`npm run build`（含类型检查）、依赖边界检查通过。`scripts/check-junction.ts`仍通过真实Rapier通路扫掠、弧墙阻挡、9个交互/返回点与旧快照拒绝；新增检查确认仅NW启用夜景样板、图片几何比例与白色无染色材质、图片退出辉光、檐口避让图片、两个高处屏壳具有碰撞。记录见 [街区检查](../block-plan/checks.json)。这些不证明实际图像颜色、透明排序、屏幕亮度和最终光影已通过。

自动采集尝试失败：Python Playwright在驱动启动阶段报 `PermissionError: [WinError 5]`；直接启动Edge和Chromium Headless Shell也在Mojo管道创建阶段报拒绝访问。没有采集到任何本轮运行截图。后续可在允许浏览器进程的终端运行：

```powershell
python scripts/capture-nw-night.py --base-url http://127.0.0.1:5173
```

脚本按时间戳保存到本目录的 `runtime/`：正面、侧面、近景、街区整体、普通行走取景，以及同机位Bloom关/反射关对照。默认Edge+SwiftShader；记录实际相机、draw calls/三角面和页面错误，软件后端不等同于真实GPU性能。当前这些输出**尚不存在**，不能把预定机位写成已验收截图。
