# 黑色湿镜面地坪（2026-10-24）

> 用户最新指令：地面风格以 Samsy 参考截图为目标，改为“黑色湿镜面地坪”，让霓虹倒影成为主要视觉内容。  
> 本文记录工作区实现、运行采集与证据边界；不把 SwiftShader 截图写成真实 GPU 验收。

## 1. 实现范围

| 文件 | 修改 | 作用 |
| --- | --- | --- |
| `src/engine/core/cityLook.ts` | 反射着色器注入升级 | 时间驱动的微波纹、5 采样适度模糊、高光压缩、蓝紫染色、湿斑遮罩与菲涅尔；反射目标分辨率按画质计算，并暴露 texel 尺寸 |
| `src/worlds/cyberpunk/theme.ts` | `CITY_LOOK` 调参 | 地面近黑蓝紫、低环境光、更强反射（scale 0.6 / 上限 1024）、湿区 0.62–0.96 |
| `src/worlds/cyberpunk/textures.ts` | `createGroundTexture()` | 近黑蓝紫基面，极弱接缝与颗粒，去掉高亮斑点 |
| `src/worlds/cyberpunk/materials.ts` | 地面/步道/广场材质 | 降低粗糙度与环境强度，保留弱金属感 |
| `src/worlds/cyberpunk/props/street.ts` | 导视与广场边线 | 贯穿广场的青色/金色细线降至 0.05/0.045 不透明度；新增四向入口阈值与 8 段短斜路缘；地灯改用局部材质 |

保留项：

- `cityLook.ts` 中并行的 `nwStudyWet`（NW 湿前庭）分支继续生效，使用更强的波纹与模糊，不被本轮统一参数覆盖。
- `layout.ts`、`colliders.ts`、`WorldEngine.ts` 的布局/灯光/入口未改；广场 12m 屏与 LM-01 位置不变。
- 低画质仍按原逻辑关闭反射与辉光，不新增降级分支。

## 2. 关键参数

| 参数 | 当前值 | 说明 |
| --- | --- | --- |
| `reflectionScale` | 0.6 | 1440×900 视口下反射目标 864×540 |
| `reflectionMaxSize` | 1024 | 大视口上限 |
| `wetMin` / `wetMax` | 0.62 / 0.96 | 大面积湿膜，保留局部较干斑块 |
| `groundRoughness` / `plainGroundRoughness` | 0.46 / 0.44 | 避免点光源在镜面上烧出白色光斑；镜面感主要来自平面反射 |
| 反射混合 | `0.5 + 0.5 × Fresnel` | 掠射角更强，垂直俯视仍可读 |
| 模糊 | 5 采样，texel ×(1.0, 1.35) | 保留文字与屏幕图形可辨认性 |
| 波纹 | 世界坐标双频正弦 × 0.0017 UV | 轻微、不规则、随时间移动 |
| 高光压缩 | `x / (1 + 0.18x)` | 限制霓虹过曝 |

## 5. 证据边界

- 截图来自 Edge + SwiftShader 软件渲染（诊断帧率约 2 fps），仅证明该机位与 HIGH 画质的可见表现；**真实 GPU、连续走动录屏、VRAM 与帧耗未验收**。
- 12m 屏当前为静态 SVG；动态倒影证据来自媒体亭动画与波纹，不是真实视频屏。
- 广场南侧的暖光池来自既有 `galleryWarm` 点光源；本轮只调地面材质，未改灯光。它是倒影之外最亮的区域，若用户认为仍偏亮，应在 `WorldEngine.ts` 的灯光范围/强度上另行调整。
- LM-01 的青色/金色轨道是展项内容，不是本轮地面导视线；其亮度未改。
- `cityLook.ts`、`theme.ts`、`materials.ts`、`street.ts` 属共享/整合文件；后续建筑任务需保留本轮的 `nwStudyWet` 分支与湿膜参数，不要用旧截图回退。
