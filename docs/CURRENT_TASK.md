## 1. 两分钟了解当前状态

LOHINA WORLD 是可操控角色探索的 3D 项目展示世界。当前只实现赛博暮光地区；风格与展示内容分别组织。

- **新街区规划（2026-10-24，待实施）**：用户已按手绘俯视图重新规划建筑群，只确认 `M`、`SCREEN`、`NW(0)`、`SW(0)`、`NE(0)`、`SE(0)`；媒体楼是 `SE(0)`，不是 `SW(0)`。编号采用“方位 + 括号整数”，其余名称、功能、尺寸、入口与编号延伸方向待定。该规划**尚未替换当前运行布局**：不要据此移动或删除现有八栋、B-01 打磨区与 LM-01。规则见 [AGENTS §0.1b](../AGENTS.md)，工程细节、待复验问题与分阶段计划见 [新街区规划记录](block-plan/README.md)。

- **B-01 打磨区（并行任务）**。按用户选择采用同世界搬迁，默认B-01由 `[-32,0,-34]` 移至 `[-55,0,3]`，碰撞同步，周围清理背景剪影。`/world?workshop=B-01` 直达楼前；结构查看可加 `&b01=structure`。保留单一建筑模块和原媒体内容，其他楼、LM-01与出生点未移动。详见 [打磨区记录](building-workshop/README.md)。此前“未改位置”说明属于搬迁前的模块记录。

本文件记录并行模块交接：下方 B-01 的媒体立面任务记录与 LM-01 记录属于各自模块，互不覆盖；各 agent 按自己已分配范围执行。

- **LM-01 本对话当前任务（2026-10-24）**：天体仪候选扩大到14m×11.8m，人物在下方 `[0,0,1]` 出生；外围拱架让出中央通路，控制台按E进入轨道中枢，页面入口由 `content/observatoryDestinations.ts` 配置。双环改为稳定分段白芯光轨，青色/蓝紫柔光，少量流光带短尾，两球保留地球/月亮模型位。构建、几何、物理和页面服务端渲染检查通过；浏览器采集仍受 WinError 5 限制，未验收实际观感与完整页面往返。详见 [最新 LM-01 记录](orrery-review/2026-10-24.md)。

- **用户当前指令**：只优化 B-01 北岸媒体楼四面立面，目标为“四面错层漫画展示 + 流动光幕”。四面各一个漫画主展位，中心高度 35% / 55% / 70% / 45%，保持原图比例；其余墙面做深色底、青蓝为主、少量暖金的缓慢上流光幕，四面不同相位，转角连续；`LOHINA` 标识移到入口与冠顶。四面布局与材质第一轮已接入，四立面截图、街区关系图、33.48s 绕楼录屏见 [B-01 记录](screenshots/b01/README.md)。未改建筑位置、入口、相机或其他建筑，未提交或推送。
- **最近视觉反馈**：用户喜欢 Neon Zenith 单栋样板的风格，尤其是光影；仍认为现有建筑像贴图，要求更清楚的实体构造。最新一轮立面细化已接入，用户尚未确认视觉通过。
- **已接入**：八栋建筑的实体窗、窗后空间、三类构造细节，以及 HIGH 下的共享地面反射和选择性辉光。主场景是 WebGL2，独立样板是 WebGPU/TSL，不是全城已迁移。
- **必须保留**：普通移动 10m/s、无冲刺、跳跃；自由拖拽、近地仰视、人物淡出和镜头碰撞；既有建筑位置、入口、内容槽及用户照片。
- **没有实现**：完整世界切换、全视口主题选择器、随观察距离切换的建筑立面 LOD。广场仍为 8m 静态屏，12m/14m 画幕仅是提案。

## 4. 从哪里启动和检查

在实际项目根目录执行，不能假定其他机器仍使用当前电脑路径。依赖与锁文件已存在；全新检出优先 `npm ci`，已有工作区先检查依赖，不必每轮重装。

| 目的 | 命令 / 地址 | 注意 |
| --- | --- | --- |
| 正常开发 | `npm run dev` → `http://127.0.0.1:5173/world` | Vite 配置 `strictPort: true`，占用时会失败；先确认现有服务，不启动重复实例 |
| B-01 / T-02 浏览器脚本 | 单独终端 `npm run dev -- --port 5174` | `b01-*.mjs`、`t02-check.mjs` 默认写死 5174，不会跟随另一个服务端口 |
| 类型 / 构建 / 分层 | `npm run typecheck`、`npm run build`、`node scripts/check-dependencies.mjs` | 每项独立记录结果；构建通过不代表视觉通过 |
| 城市几何 / 后期状态 | 城市建筑记录中的 PowerShell 打包与执行命令 | `.camera-preview/*.mjs` 是本地生成物，全新检出需先生成；不要直接执行 TS 文件 |
| 城市连续操作采集 | 服务启动后 `python scripts/capture-city-style.py` | 需要 Python Playwright 和可用的 Edge；检查脚本中的地址及浏览器配置 |

5173 曾运行本地 esbuild 静态预览，页面能打开不证明当前就是 Vite 或带热更新；接手先确认监听进程与启动命令。`.camera-preview/` 中的辅助服务和 HTML 被忽略，不属于可移植启动契约；其他机器以仓库的 Vite 配置为准。不要在没有确认运行工程时只修改 GitHub 副本。
