## 4. 从哪里启动和检查

在实际项目根目录执行，不能假定其他机器仍使用当前电脑路径。依赖与锁文件已存在；全新检出优先 `npm ci`，已有工作区先检查依赖，不必每轮重装。

| 目的 | 命令 / 地址 | 注意 |
| --- | --- | --- |
| 正常开发 | `npm run dev` → `http://127.0.0.1:5173/world` | Vite 配置 `strictPort: true`，占用时会失败；先确认现有服务，不启动重复实例 |
| B-01 / T-02 浏览器脚本 | 单独终端 `npm run dev -- --port 5174` | `b01-*.mjs`、`t02-check.mjs` 默认写死 5174，不会跟随另一个服务端口 |
| 类型 / 构建 / 分层 | `npm run typecheck`、`npm run build`、`node scripts/check-dependencies.mjs` | 每项独立记录结果；构建通过不代表视觉通过 |
| 城市几何 / 后期状态 | 城市建筑记录中的 PowerShell 打包与执行命令 | `.camera-preview/*.mjs` 是本地生成物，全新检出需先生成；不要直接执行 TS 文件 |
| 城市连续操作采集 | 服务启动后 `python scripts/capture-city-style.py` | 需要 Python Playwright 和可用的 Edge；检查脚本中的地址及浏览器配置 |

5173 曾运行本地 esbuild 静态预览，页面能打开不证明当前就是 Vite 或带热更新；接手先确认监听进程与启动命令。`.camera-preview/` 中的辅助服务和 HTML 被忽略，不属于可移植启动契约；其他机器以仓库的 Vite 配置为准。不要在没有确认运行工程时只修改 GitHub 副本。
