# B-01 同世界建筑打磨区

2026-10-24 用户要求把一栋建筑“挪到空地”，方便继续打磨。本轮默认处理最近迭代的 B-01 北岸媒体楼；它仍在原世界中，沿用角色、镜头、灯光和媒体内容，不是独立模型查看器。

## 查看

启动开发服务后打开 `/world?workshop=B-01`，完成引导即在新楼前方查看。继续用 WASD 行走、鼠标拖拽/滚轮看楼。结构模式可使用 `/world?workshop=B-01&b01=structure`，关闭漫画与光幕审阅结构；这不是最终媒体模式的画面。

开发控制台也可执行 `window.__lohina.buildingWorkshop()`。直达功能仅在开发模式启用；楼体搬迁本身也会出现在生产构建中。

## 位置与范围

- 原位置：`[-32,0,-34]`；当前打磨位置：`[-55,0,3]`，广场西侧。
- 默认站立点：`[-55,0,17]`，朝建筑正面查看。
- 单一原建筑整体搬迁，未复制第二栋；几何、四面漫画/光幕、局部灯光与内部媒体插槽保持相同模块。
- `worldColliders` 由当前 `BuildingSpec.position` 生成，楼体碰撞同步搬迁。
- 新位置周围设置32m背景楼中心避让区，提供近距离查看与绕行空间；不是新增实心围栏，也不拦角色通行。
- 其他建筑、天体仪与出生点没有移动。布局版本已更新，旧会话位置会重新校验。

位置入口是 `src/worlds/cyberpunk/layout.ts` 的 `BUILDING_WORKSHOP`，B-01 的 `position` 引用该配置。打磨主体代码仍在 `buildings/heroMedia.ts`；四面内容、比例、位置和光幕参数在 `buildings/b01MediaConfig.ts`。共用 `cityStyle.ts` 会影响其他楼，不能当作 B-01 私有文件修改。
