## 本轮目标与结果

目标是“四面错层漫画展示 + 流动光幕”：

- 四面各有一个漫画主展位，使用用户提供的两张图。
- 四个展位高度明显不同，形成错层；宽度、高度、水平位置也不同。
- 漫画保持原图宽高比、完整显示、四周留白，不拉伸、不裁切。
- 窗、梁、装饰杆和文字不穿过漫画区域。
- 从正面开始逐层升高，背面最高、左面居中，绕楼时能连续发现四个展位。
- 剩余墙面是深色底上的青蓝光幕，少量暖金束；四面同一视觉语言，不同相位。
- 漫画用深色凹入背板、内衬、细框、上下支撑臂与遮光檐安装，属于立面而不是漂浮贴图。
- 冠顶与入口上方保留 `LOHINA` 标识；正立面旧品牌墙牌已移除。

## 四面展位配置

配置模块：`src/worlds/cyberpunk/buildings/b01MediaConfig.ts`。改图片、尺寸、高度比例、水平偏移和光幕相位只需改这个文件。

可用塔身高度为裙房顶 `7.2m` 到冠顶起点 `32.4m`，共 `25.2m`；`centerRatio` 是相对这段高度的比例。

| 立面 | 图片 | 原图比例 | 展位尺寸 | 中心高度 | 高度比例 | 水平偏移 `centerU` |
| --- | --- | --- | --- | --- | --- | --- |
| 正面 front | `images/w700d1q75cms.jpg` | 640 × 576（1.111） | 6.80 × 6.12m | 16.02m | 35% | +0.45m |
| 右面 right | `images/images1.jpg` | 447 × 447（1.000） | 5.40 × 5.40m | 21.06m | 55% | −0.75m |
| 背面 back | `images/w700d1q75cms.jpg` | 640 × 576（1.111） | 5.60 × 5.04m | 24.84m | 70% | +2.45m |
| 左面 left | `images/images1.jpg` | 447 × 447（1.000） | 4.90 × 4.90m | 18.54m | 45% | −0.50m |

- 展位高度由 `width / aspect` 计算，不单独写死，避免比例漂移。
- 背面横向偏移 +2.45m 是为避开 `x≈1.4` 的楼梯核心竖带；东立面竖鳍在漫画洞口处断开，层间板、窗和设备板按矩形避让。
- 正面 `posterSlots` 仍登记为 `mainScreen`，城市窗与共享逻辑继续避开该区域。
- 四个面板按各自立面 yaw 朝外；截图确认背面、左面文字与线稿方向正确，没有镜像或反向。

## 安装构造与材质

- 深色凹入背板：比漫画每边大 0.36m，厚 0.16m，先封住原立面的窗和背板，避免窗格穿过漫画。
- 金属内衬：比漫画每边大 0.13m，位于背板前方，形成一圈凹入阴影。
- 四边细框：外扩 0.46m，厚 0.22m，明确展位的安装边界。
- 上下支撑臂、顶部遮光檐和底部暖金收边：把面板与塔身结构连接起来。
- 漫画平面使用 `MeshBasicMaterial`、`toneMapped: false` 和暖灰 tint（`0xccd1cf`–`0xd8dcda`），保留白底线稿，同时压低纸面亮度。
- 漫画面板不满足 `CityLook` 的选择性辉光规则（无 `userData.bloom`、无自发光、不是双色 shader），因此不会被 bloom 放大成白色发光板。
- 纹理按 `SRGBColorSpace` 加载，开启各向异性与 Clamp；运行时若纹理比例与配置相差超过 0.01 会输出警告。

## 流动光幕

- 实现为 `ShaderMaterial` + `AdditiveBlending` + `depthWrite: false`，`renderOrder = 2`，`onBeforeRender` 更新 `uTime`；没有改 `WorldEngine`。
- 每面 4 道宽束、7 道窄束、2 道暖金束；宽度、位置和脉冲相位由立面局部坐标与种子决定。
- 光束沿 Y 缓慢上流，单循环约 16–21 秒；有亮头、拖尾、局部熄灭和底部极暗底光，保留暗部。
- 青色为主，暖金只占少量；四面相位分别为 `0.05 / 0.33 / 0.61 / 0.82`，速度 `0.052 / 0.061 / 0.047 / 0.057`。
- 漫画矩形在 shader 中按 `uComicCenter / uComicHalf` 清空，边缘留 0.34m 羽化，因此光幕不会压过漫画。
- 四角有 `0.06 × 24.8 × 0.06m` 青蓝光带，跨转角连续；光幕自身在立面左右边缘 0.9m、上下边缘 1m 内淡出。

## 结构模式

`?b01=structure` 保留本轮新增的凹入背板、内衬、细框、支撑臂、遮光檐和收边，只隐藏漫画贴图、光幕与增强灯。这样仍能检查“漫画装在什么结构上”，而不是把媒体洞留成空白。

## 复现命令

脚本写死 `http://127.0.0.1:5174/world` 与本机 Edge 路径，可设置 `LOHINA_URL` 覆盖；生产预览没有 `window.__lohina` 调试桥，必须连接开发服务器。

```bash
npm run dev -- --port 5174

node scripts/b01-facades.mjs     # 四立面 + 街区关系 + 绕楼录屏/抽帧
node scripts/b01-structure.mjs   # ?b01=structure 7 张

```

脚本使用 Playwright + Edge + SwiftShader（1440×900），每张图打印 calls / 三角面。它们只用于固定机位回归，不代表真实 GPU 性能。
